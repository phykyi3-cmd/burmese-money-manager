မေးလေ့ရှိသော မေးခွန်းများ (FAQ)

Money Manager နှင့် ပတ်သက်၍ သိလိုသည်များ

တကယ်ပဲ ၁၀၀% အခမဲ့ သုံးလို့ရတာလား?

ဟုတ်ကဲ့၊ လုံးဝ ၁၀၀% အခမဲ့ ဖြစ်ပါသည်။ မည်သည့် လစဉ်ကြေး၊ နှစ်စဉ်ကြေး သို့မဟုတ် ဝှက်ထားသော ကုန်ကျစရိတ်မျှ မရှိဘဲ တစ်သက်တာ အခမဲ့ သုံးနိုင်ပါသည်။

ငါ့ရဲ့ ငွေစာရင်းအချက်အလက်တွေ လုံခြုံပါ့မလား?

အလွန်လုံခြုံပါသည်။ သင့်စာရင်းအချက်အလက်အားလုံးသည် သင့်စက်၏ Browser (LocalStorage) ထဲတွင်သာ တည်ရှိပြီး မည်သည့်ပြင်ပ Server သို့မျှ ဒေတာမပို့သဖြင့် သင့်ကိုယ်တိုင်မှလွဲ၍ မည်သူမျှ မမြင်နိုင်ပါ။

အင်တာနက် မရှိဘဲ Offline သုံးလို့ရသလား?

သုံးလို့ရပါသည်။ Progressive Web App (PWA) နည်းပညာဖြင့် ဖုန်းထဲတွင် တင်ထားပြီးပါက အင်တာနက်လိုင်း လုံးဝမရှိသည့်အချိန်တွင်လည်း စာရင်းများ ပုံမှန်အတိုင်း သွင်းနိုင်၊ စစ်ဆေးနိုင်ပါသည်။

နိုင်ငံခြားငွေ (USD / THB) ပြောင်းသုံးလို့ရသလား?

ရရှိပါသည်။ MMK (Ks) အပြင် USD ($) နှင့် THB (฿) တို့ကို App ထဲတွင် တစ်ချက်နှိပ်ရုံဖြင့် အလွယ်တကူ ပြောင်းလဲသတ်မှတ်နိုင်ပါသည်။

သင့်ဘဏ္ဍာရေးကို အခုပဲ စတင်ပြောင်းလဲလိုက်ပါ

ငွေဘယ်လောက်ကုန်သွားလဲ စိတ်ညစ်မနေပါနဲ့တော့။ Money Manager ဖြင့် စနစ်တကျ မှတ်တမ်းတင်ပြီး ငွေစုပန်းတိုင်များကို အောင်မြင်စွာ တည်ဆောက်ပါ။
